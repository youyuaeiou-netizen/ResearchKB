# ResearchKB 研究身份与需求（v3 草案）

## 身份与工作方式

- 我是材料科学研究者，维护本地优先、证据可追溯的 ResearchKB。
- Zotero 是书目、PDF 与引用的权威来源；Obsidian 用于浏览、审阅与人工确认；Codex 在 `.harness` 中执行采集、去重、候选编译、查询、Lint 与报告。
- 自动化只能产生可审核候选，不能替代实验判断、证据核验或正式知识晋级。

## 当前研究优先级

1. 金属增材制造，尤其是激光粉末床熔融（LPBF）。
2. 工艺—缺陷—显微组织—性能关系，以及原位监测和质量控制。
3. 材料表征、凝固与相变、腐蚀、焊接冶金、能源材料。
4. 材料机器学习：仅在数据、特征、验证条件和可解释性明确时纳入候选。

## 知识准入与输出要求

- 优先：Zotero 文献、DOI/公开元数据、官方期刊 RSS、受审阅的 GitHub 项目、用户主动导入的本地资料。
- 每项候选都要保留来源 URL/DOI/路径、证据位置、内容哈希、采集时间与运行编号。
- 明确区分正式知识、候选知识、原始证据和推断；不得自动标记 `verified`、`reusable`，不得自动晋级到 `02-Areas`、`01-Projects` 或 `05-Skills`。
- 对声称实验性能、工艺窗口、机理或模型效果的内容，必须标记缺失条件，不能补造数值或因果结论。

## 信号过滤偏好

- 优先高信息密度的论文、数据集、开源材料计算/表征/工艺工具、软件发布和可复现实验资源。
- 降低与研究无关的泛 AI 新闻、消费电子、融资宣传、无证据观点和重复转载的优先级。
- GitHub 只跟踪用户确认的公开账号活动和公开仓库 release；X 仅采集用户审核账号的 profile 时间线，不使用关键词搜索，禁用 replies 与回复扩展。X 采用 Apify/Scweet 第三方采集，每日最多一次；每次请求携带精确 UTC 时间窗口、`exclude_replies` 和 $0.145 的远端费用上限，月度本地预留上限 $4.50（31 次最多 $4.495，至少保留 $5 Free Plan 的 10% 额度）。不使用 Playwright、登录绕过或反爬规避。没有令牌或预算余量时安全跳过，手动导入仍是备用路径。
