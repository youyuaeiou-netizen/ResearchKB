ObsUI / Codex 视觉重构参考素材

优先级：
1. 01_shell_exact/：最高优先级。用户已经确认的外壳、尺寸比例和五个 Tab 选中态参考。
2. 02_target_game_keyframes/：目标游戏的视觉设计系统参考。重点观察颜色、材质、组件结构、排版、间距、信息密度、边框、高光/阴影和细节一致性。
3. 目标游戏原视频 VID20260823011302(2).mp4：主要用于观察 Tab/内容切换、横向滑动、出现顺序和整体动画节奏。
4. 03_current_obsui_keyframes/：当前实现，仅用于识别差距，不应作为新的视觉基准。
5. 当前 ObsUI 原视频 VID20260823201149(1).mp4：用于确认当前实际渲染和交互状态。

重要约束：
- 不要复刻手机拍摄产生的透视、摩尔纹、曝光变化、屏幕反光或游戏背景。
- 目标是复刻游戏 UI 本身的设计语言，而不是复制游戏中的具体文字和业务内容。
- 保留现有业务逻辑、数据逻辑、状态管理和可用交互；视觉层按参考素材系统性重构。
- 01_shell_exact 中已经确认的整体外壳和 Tab 选中视觉不要擅自重新设计。
- 不要继续在旧 CSS 上零散堆补丁；建立统一 design tokens 和公共组件后再推广到全部 Tab。
- 静态视觉一致性优先于动画。先校准尺寸、比例、排版、颜色、材质和细节，再处理转场。
