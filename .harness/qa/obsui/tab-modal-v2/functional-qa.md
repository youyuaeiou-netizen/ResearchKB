# TabModalV2 QA — 2026-08-25

## 功能验收

- `?ui=tab-v2` 进入 V2；无 query 时仍显示旧版总览，点击“状态监控”仍打开旧版 `device-workspace`。
- V2 首次进入选中“本机”；五个 Tab 顺序与文案固定为“目标 / 本机 / 仓库 / 文献 / H.D.D”。业务映射为：目标→`planner`、本机→`monitor`、仓库→`repository`、文献→`library`、H.D.D→`hdd`。
- 五个 Tab 逐一点击后均保持唯一 `aria-selected=true`；外框、Tab 轨道、关闭按钮在 1920×1080 CSS 视口的五状态坐标一致：外框 `1780×910`，Tab 轨道 `1464×83`，关闭按钮 `84×83`。
- 左栏选中项使用蓝色块、分隔线和固定行高；点击“网络连接”后内容标题切换为“网络连接”。
- CardRail 在浏览器中实际从 `scrollLeft=0` 变为 `212`，到达末端时右箭头禁用；单元测试覆盖起点/终点箭头边界和卡片轨道 DOM 稳定性。
- 关闭 V2 返回总览；从首页“状态监控”打开后，关闭可将焦点恢复到原触发按钮。
- V2 五页未渲染旧 `device-panel-content`、`device-tabs`、`device-shell-image` 或旧 `hdd-page` 节点；H.D.D 页面使用独立 V2 DOM，并复用本机桥接请求/流式会话能力。
- 浏览器控制台 `error/warn`：空。

## 视口与 DPI

- 1920×1080：通过；`devicePixelRatio=1`。
- 2560×1440：通过；外框保持固定上限并居中，Tab/关闭按钮坐标随外框稳定。
- 等效 125% DPI：CSS 视口 1536×864，`devicePixelRatio=1.25`，通过。
- 等效 150% DPI：CSS 视口 1280×720，`devicePixelRatio=1.5`，通过。
