# 扩散及其分类

## 扩散的基本概念

物质迁移可以通过对流和扩散两种方式实现。气体、液体中通常同时存在对流与扩散；固体中没有宏观对流，扩散是原子或分子依靠热振动，从一个平衡位置迁移到另一个位置的物质传输过程。

扩散是固体材料中的重要现象，参与铸件凝固后的均匀化、[[02-Areas/材料科学/08_固态相变/01_固态相变的特点及分类#固态相变|固态相变]]、烧结、表面处理、焊接接头成分调整、蠕变，以及[[02-Areas/材料科学/04_变形与回复再结晶/03_回复与再结晶#回复与再结晶|回复和再结晶]]等过程。研究扩散有两个互补层面：

1. **表象理论**：用扩散通量、浓度梯度和扩散系数描述物质传输的速率和数量。
2. **原子理论**：说明原子通过什么位置、沿什么路径以及以什么热激活过程迁移。

扩散不等于“浓度必然按表观浓度梯度变均匀”。实际结果还取决于化学势、边界条件、相平衡、温度场、应力场、晶体缺陷和扩散路径。

## 扩散的分类

| 分类标准 | 类型 | 定义与辨析 |
|---|---|---|
| 是否发生可观测的组元浓度重新分布 | 自扩散 | 原子在自身元素的晶体点阵中迁移；没有示踪或同位素标记时，宏观成分通常不发生可见变化 |
|  | 互扩散 | 原子进入另一组元的晶体点阵并造成组元重新分布 |
| 相对于浓度梯度的表观方向 | 下坡扩散 | 原子由高浓度处向低浓度处迁移 |
|  | 上坡扩散 | 原子由低浓度处向高浓度处迁移；它可能由化学势梯度与浓度梯度方向相反造成 |
| 是否形成新相 | 原子扩散 | 扩散过程中不出现新的相，主要表现为原子重新分布 |
|  | 反应扩散 | 扩散伴随新相形成，形成中间相、固溶体层或其他反应层 |
| 原子迁移路径 | 体扩散 | 在晶粒内部的晶体点阵中进行的扩散 |
|  | 短路扩散 | 沿表面、晶界、位错等缺陷区域进行的扩散 |

这些分类标准彼此独立，可以同时使用。例如，置换型二元合金中的互扩散可以通过空位机制完成，也可以沿晶界短路进行；上坡或下坡描述的是相对于浓度梯度的表观方向，并不取代对化学势驱动力的判断。

## 如何选择扩散模型

分析扩散问题时，先按以下顺序确定模型：

1. 确认扩散对象、相组成，以及是否存在宏观流动。
2. 明确初始浓度、表面浓度、无穷远浓度、封闭边界或相界面条件。
3. 若温度均匀、相区不变且 D 可视为常数，使用常数 D 的菲克方程解。
4. 若 D 随浓度、相区或扩散路径变化，使用浓度相关的方程、相似变量或 Matano 分析。
5. 若有新相形成或相界面移动，使用[[02-Areas/材料科学/03_扩散/07_反应扩散#定义|反应扩散]]模型，同时考虑相平衡和界面条件。
6. 最后结合[[02-Areas/材料科学/01_固体结构/03_晶体学基础#空间点阵、晶胞与晶体结构|晶体结构]]、[[02-Areas/材料科学/02_晶体缺陷/02_点缺陷#空位、间隙原子与复合缺陷|空位/间隙缺陷]]、晶界和位错判断主导的原子机制。

## 易错点

- 浓度梯度是表观驱动力，真正的热力学驱动力是化学势梯度；两者方向不一定相同。
- “自扩散”和“互扩散”按组元示踪与浓度变化区分；“体扩散”和“短路扩散”按迁移路径区分，不能混为一组概念。
- 反应扩散不是普通菲克扩散的简单延长；新相形成会改变相平衡、边界条件和界面位置。
- 短路路径的局部扩散系数通常较大，但其体积分数小，宏观通量还取决于路径连通性、晶粒尺寸、偏聚和温度。
