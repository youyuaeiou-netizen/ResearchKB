# 固态互不溶解的三元共晶相图

## 相图构成

三个组元液态完全互溶、固态互不溶，并且三个二元系均为简单共晶。三个初晶液相面分别对应初晶 $A$、$B$、$C$；相邻液相面交于三条共晶谷：

$$
e_1E:\ L\rightarrow A+B,
$$

$$
e_2E:\ L\rightarrow B+C,
$$

$$
e_3E:\ L\rightarrow A+C.
$$

三条共晶谷汇聚于三元共晶点 $E$，发生

$$
L_E\rightarrow A+B+C.
$$

此时液相 $L_E$ 与三个固相成分 $A$、$B$、$C$ 构成四相平衡，共晶温度及各相成分固定；四相平衡面为由三个固相成分点构成的三角形。

三条液相面分别为 $ae_1Ee_3a$、$be_1Ee_2b$、$ce_2Ee_3c$。四相平衡共晶平面 $mnp$ 由三个三相平衡连接三角形合并而成：$mEn$ 是 $L\rightarrow A+B$ 三相区的底面，$nEp$ 是 $L\rightarrow B+C$ 三相区的底面，$pEm$ 是 $L\rightarrow A+C$ 三相区的底面。低于 $E$ 点温度，合金全部凝固，形成 $A+B+C$ 三相区。

| 要点 | 分类 | 含义 |
|---|---|---|
| 点 | $a$ | 组元 $A$ 的熔点 |
| 点 | $b$ | 组元 $B$ 的熔点 |
| 点 | $c$ | 组元 $C$ 的熔点 |
| 液相面 | $ae_1Ee_3a$ | 组元 $A$ 的初始结晶面 |
| 液相面 | $be_1Ee_2b$ | 组元 $B$ 的初始结晶面 |
| 液相面 | $ce_2Ee_3c$ | 组元 $C$ 的初始结晶面 |
| 共晶转变线 | $e_1E$ | $L\rightarrow A+B$ |
| 共晶转变线 | $e_2E$ | $L\rightarrow C+B$ |
| 共晶转变线 | $e_3E$ | $L\rightarrow A+C$ |
| 三元共晶点 | $E$ | $L_E\rightarrow A+B+C$ |
| 四相平衡共晶平面 | $mnp$ | / |

## 相区与截面

三个液相面以下分别存在 $L+A$、$L+B$、$L+C$ 两相区。每条共晶谷对应一个液相与两个固相共存的三相区域；三个三相区域在 $E$ 处汇合。三元共晶温度以下，整个成分范围内均为 $A+B+C$。

垂直截面可显示初晶、[[02-Areas/材料科学/06_二元相图与合金的凝固/03_二元相图分析#2. 共晶相图及其合金凝固|二元共晶]]和三元共晶依次出现的温度范围。水平截面在不同温度下依次截取液相面、三相区域和四相平衡面，可用来识别同一温度下的相态与平衡关系。

![固态互不溶三元共晶垂直截面](<./_attachments/图7-19_固态互不溶三元共晶垂直截面.png>)

*图7-19 固态互不溶三元共晶相图的垂直截面。*

若截面成分轴平行于 $AC$ 边，总成分点位于截面线 $rs$ 上，合金冷却时可依次经历：点 1 开始从液相析出初晶 $A$；点 2 进入 $L+A+C$ 三相区并发生 $L\rightarrow A+C$；点 3 到达四相共晶平面并发生 $L\rightarrow A+B+C$。三元共晶反应后不再有其他相变，室温组织为初晶 $A$、二相共晶 $(A+C)$ 与三相共晶 $(A+B+C)$。若垂直截面通过顶点 $A$，该截面与 $L+A$ 两相过渡面的截线可在特定位置呈水平连接线，但这不改变一般垂直截面不能用于相量计算的限制。

## 投影图与凝固过程

投影图中，三条共晶谷把成分三角形分成三个初晶区。液相面上的箭头和等温线指示液相成分随降温向较低温度方向移动。

![固态互不溶三元共晶投影](<./_attachments/图7-21_固态互不溶三元共晶投影.png>)

*图7-21 三条共晶谷、三个初晶区、液相面等温线和典型冷却路径的投影。*

以初晶 $A$ 区内的合金为例：

1. 液相到达 $A$ 初晶面后析出 $A$，液相成分沿总成分点与 $A$ 顶点连线的延长方向移动；
2. 液相成分到达 $e_3E$ 后发生 $L\rightarrow A+C$，液相沿共晶谷向 $E$ 移动；
3. 到达 $E$ 后剩余液相全部发生 $L_E\rightarrow A+B+C$；
4. 室温组织由初晶 $A$、二元共晶 $(A+C)$ 和三元共晶 $(A+B+C)$ 组成。

初晶阶段可由[[02-Areas/材料科学/06_二元相图与合金的凝固/02_相图热力学的基本要点#3. 杠杆法则|杠杆定律]]求相量。例如总成分为 $O$，液相到达共晶谷上的 $q$ 点时，若 $A$、$O$、$q$ 共线，则

$$
w_A=\frac{Oq}{Aq},\qquad w_L=\frac{AO}{Aq}.
$$

若以百分数表示，则上式各自乘以 $100\%$。液相刚到达共晶谷 $e_3E$ 的 $q$ 点时，二相共晶 $(A+C)$ 尚近于零；其瞬时成分点是过 $q$ 点作液相面切线与 $AC$ 边的交点 $d$。继续冷却时，液相成分沿 $qE$ 移动，每一瞬间形成的 $(A+C)$ 共晶成分由共晶谷相应液相点的切线与 $AC$ 边的交点确定。液相到达 $E$ 时，先后形成的 $(A+C)$ 共晶平均成分为 $f=Eq\cap AC$。因此，总量为 $w_0$ 的合金中，二相共晶与三相共晶的质量分数分别为

$$
\frac{w_{(A+C)}}{w_0}
=\frac{Eq}{Ef}\frac{AO}{Aq}\times100\%,
$$

$$
\frac{w_{(A+B+C)}}{w_0}
=\frac{qf}{Ef}\frac{AO}{Aq}\times100\%.
$$

## 室温组织的区域规律

**表7-4 固态完全不溶、具有共晶转变的三元合金系中典型合金的室温组织**

| 区域 | 室温组织 |
|---|---|
| 1 | 初晶 $A$ + 二相共晶 $(A+B)$ + 三相共晶 $(A+B+C)$ |
| 2 | 初晶 $B$ + 二相共晶 $(A+B)$ + 三相共晶 $(A+B+C)$ |
| 3 | 初晶 $B$ + 二相共晶 $(B+C)$ + 三相共晶 $(A+B+C)$ |
| 4 | 初晶 $C$ + 二相共晶 $(B+C)$ + 三相共晶 $(A+B+C)$ |
| 5 | 初晶 $C$ + 二相共晶 $(A+C)$ + 三相共晶 $(A+B+C)$ |
| 6 | 初晶 $A$ + 二相共晶 $(A+C)$ + 三相共晶 $(A+B+C)$ |
| $AE$ 线 | 初晶 $A$ + 三相共晶 $(A+B+C)$ |
| $BE$ 线 | 初晶 $B$ + 三相共晶 $(A+B+C)$ |
| $CE$ 线 | 初晶 $C$ + 三相共晶 $(A+B+C)$ |
| $e_1E$ 线 | 二相共晶 $(A+B)$ + 三相共晶 $(A+B+C)$ |
| $e_2E$ 线 | 二相共晶 $(B+C)$ + 三相共晶 $(A+B+C)$ |
| $e_3E$ 线 | 二相共晶 $(A+C)$ + 三相共晶 $(A+B+C)$ |
| $E$ 点 | 三相共晶 $(A+B+C)$ |

- 三个初晶区分别形成“初晶 $A/B/C$ + 相邻二元共晶 + 三元共晶”。
- $AE$、$BE$、$CE$ 上分别为初晶 $A$、$B$、$C$ 与三元共晶。
- $e_1E$、$e_2E$、$e_3E$ 上分别为二元共晶 $(A+B)$、$(B+C)$、$(A+C)$ 与三元共晶。
- $E$ 点仅形成三元共晶 $(A+B+C)$。

投影图中相邻区域的平衡相或组织组成通常只相差一个组成部分，可据此检查相区判定是否连续。
