# 三元相图举例

## Fe-C-Si 三元系垂直截面

固定硅含量的 Fe-C-Si 垂直截面平行于 [[02-Areas/材料科学/06_二元相图与合金的凝固/04_铁碳相图#1. 相图组成|Fe-C]] 成分边，可用于分析灰口铸铁中碳、硅含量与组织转变的关系。典型截面包含四个单相区：液相 $L$、铁素体 $\alpha$、高温铁素体 $\delta$ 和奥氏体 $\gamma$，并包含若干两相区和三相区。

硅质量分数分别为 $2.4\%$、$4.8\%$ 的两个截面中，各有 4 个单相区、7 个两相区和 3 个三相区。包晶、共晶、共析三相平衡区均由若干界线围成，不是二元相图中的单条水平线。

![Fe-C-Si垂直截面](<./_attachments/图7-54_Fe-C-Si垂直截面.png>)

*图7-54 硅质量分数分别为 2.4% 和 4.8% 的 Fe-C-Si 垂直截面。*

主要三相转变包括

$$
L+\delta\rightarrow\gamma,
$$

$$
L\rightarrow\gamma+C,
$$

$$
\gamma\rightarrow\alpha+C.
$$

在三元垂直截面中，这些三相平衡通常表现为由若干边界线围成的区域，而不是[[02-Areas/材料科学/06_二元相图与合金的凝固/01_二元相图基本知识#4. 相律分析|二元相图]]中的单条水平线。随硅含量增加，包晶转变温度降低，共晶和共析转变温度升高，$\gamma$ 相区逐渐缩小。

## Fe-Cr-C 三元系相图

Fe-Cr-C 是铬不锈钢、含铬工具钢及高碳高铬模具钢的重要基础体系。固定铬质量分数为 $13\%$ 的垂直截面包含 $L$、$\alpha$、$\delta$、$\gamma$ 四个单相区，以及多个两相区、三相区和三条四相平衡水平线。

该截面共有 4 个单相区、8 个两相区、8 个三相区和 3 条四相平衡水平线。三条四相反应温度分别为 $1175\ ^\circ\mathrm{C}$、$795\ ^\circ\mathrm{C}$ 和 $760\ ^\circ\mathrm{C}$。

图中的碳化物含义为：

- $C_1$：以 $Cr_7C_3$ 为基础并溶有 Fe 的碳化物；
- $C_2$：以 $Cr_{23}C_6$ 为基础并溶有 Fe 的碳化物；
- $C_3$：以 $Fe_3C$ 为基础并溶有 Cr 的合金渗碳体。

![Fe-Cr-C垂直截面](<./_attachments/图7-55_Fe-Cr-C垂直截面.png>)

*图7-55 铬质量分数为 13% 的 Fe-Cr-C 垂直截面。*

| $L\rightarrow C_1$ | $\gamma\rightarrow\alpha+C_1$ | $\gamma+C_1\xrightarrow{760\ ^\circ\mathrm{C}}\alpha+C_3$ |
| $\alpha\rightarrow\gamma$ | $\gamma+C_1\rightarrow C_2$ |  |
| $\gamma\rightarrow\alpha$ | $\gamma\rightarrow\alpha+C_1$ |  |
| $\gamma\rightarrow C_1$ | $\gamma+C_1\rightarrow C_3$ |  |
| $\gamma\rightarrow C_2$ | $\alpha+C_1+C_2$ |  |

## Fe-Cr-C 水平截面

在 $1150\ ^\circ\mathrm{C}$ 和 $850\ ^\circ\mathrm{C}$ 的水平截面中，可见 $\alpha$、$\gamma$、$C_1$、$C_2$、$C_3$ 等单相区；$1150\ ^\circ\mathrm{C}$ 截面还含液相区。每个三相平衡区呈三角形，三角形顶点与相应单相区相接，相邻三相区之间由两相区隔开。

![Fe-Cr-C水平截面](<./_attachments/图7-56_Fe-Cr-C水平截面.png>)

*图7-56 Fe-Cr-C 三元系在 1150 ℃ 和 850 ℃ 的水平截面。*

水平截面适于确定指定温度下的平衡相、相成分及相量；垂直截面适于沿固定成分关系追踪温度变化。二者应配合使用，不能用垂直截面中的线段替代[[02-Areas/材料科学/07_三元相图/01_三元相图基本知识#连接线、杠杆定律与重心定律|等温连接线]]。
